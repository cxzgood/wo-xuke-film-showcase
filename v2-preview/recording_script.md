# V2 真人录音脚本

当前样片使用旧版 AI 原始分句音频作节奏参考；下面是重写的真人录音稿，字幕将在录音导入后切换。

可逐句保存为 voice/user/A01.wav … B03.m4a；也可分别录 A.wav、B.wav，严格按下列三句话顺序，句间停0.8秒。程序按实际停顿切分，不冒充语音识别；停顿不足会报错而非猜测。

## A01 · 建议窗口 2.8–8.8 秒（不用讲满，按实际语速调整）
正文：一个“我”，从来不是独自生活。
语气：平静、贴近观众，不要播音腔；停顿：句末停0.8秒；重音：我 / 生活。

## A02 · 建议窗口 10.0–16.2 秒（不用讲满，按实际语速调整）
正文：家庭的关心、社会的目光，都可能走进身体的决定。
语气：前半段温和，后半段稍加重量；停顿：关心后轻停；句末停0.8秒；重音：关心 / 目光 / 身体。

## A03 · 建议窗口 17.0–24.0 秒（不用讲满，按实际语速调整）
正文：当关心变成干预，自己的身体，究竟由谁许可？
语气：收住情绪，提出问题，不喊口号；停顿：干预后停0.4秒；问题后留白；重音：干预 / 自己 / 许可。

## B01 · 建议窗口 31.0–39.5 秒（不用讲满，按实际语速调整）
正文：一场手术，本来是个人的健康决定。
语气：明确、克制，像与同学讨论；停顿：手术后轻停；句末停0.8秒；重音：个人 / 健康 / 决定。

## B02 · 建议窗口 40.6–49.0 秒（不用讲满，按实际语速调整）
正文：为什么进入家庭关系，就需要一再说明和解释？
语气：将疑问落在具体行动上；停顿：家庭关系后停0.3秒；句末停0.8秒；重音：一再 / 说明 / 解释。

## B03 · 建议窗口 52.3–58.0 秒（不用讲满，按实际语速调整）
正文：影片值得追问的，是谁能够决定，又是谁必须解释。
语气：放慢最后半句，保留思考空间；停顿：决定后停0.4秒；结尾至少留2秒；重音：谁 / 决定 / 解释。

镜头中的“谁能决定／谁必须解释”是分析提问，不是虚构电影对白。
A段约30秒；B段约30秒。不要为赶时长加速；过长时程序会伸展对应镜头。
允许编辑已获授权的电影片段后，原声应单独进入 dialogue 轨。当前没有电影原声；示范原声电平目标约 -22 LUFS、分析旁白约 -19 LUFS，讲话时对白下压约12dB，原声独听段恢复。
